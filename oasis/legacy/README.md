# Archived integrations

Historical agent, clock and platform integrations live here for source attribution and optional
compatibility experiments. AgoraWorld, account sessions and experiment jobs do not import this runtime.
Small modules at the old import locations forward explicit legacy callers here. Install
`requirements-legacy.txt` only when these integrations are needed; CAMEL / neural-recommender tests
are not part of the native sandbox validation.

The original Apache-2.0 copyright headers are retained. Upstream reference and baseline commit are
recorded in `docs/upstream.md`.
