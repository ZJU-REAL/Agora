# 推荐、浏览会话与可视化

新的沙盒入口为 `python -m agora` / `agora`，与原 Arena 共用世界存储。命令和演示见
[README](../README.md)。格式为 `agora-session-v1`，策略为 `agora-hybrid-v1`。
默认配置见 [recommendation.hybrid.json](../configs/environments/recommendation.hybrid.json)。

## 一次刷新

1. 在可见内容中召回：新内容、关注作者、兴趣话题、热门和种子决定的探索窗口。每路至多
   `channel_limit` 条，去重后的候选数最多为五路之和；不向用户推荐自己的帖子。
2. Persona 兴趣作先验，最近 1,000 条行为反馈按 tick 指数衰减，主题权重限于 [-3, 3]。
   打开 +0.15、赞 +0.7、收藏 +1、评论 +0.3；停留每次打开最多累计 +0.4。取消赞/收藏
   有反向权重；重复数据库动作不产生新正反馈。评论代表兴趣而非正向情绪。
3. 组合话题亲和、关注、质量、时效与疲劳。质量使用平滑观测点击率和有上限的 log
   互动量；最近 48 tick 的重复曝光产生惩罚。显式“不感兴趣”移除此帖并降低主题权重。
4. 逐条构造至多 `slate_size` 条列表，重复作者/话题有软惩罚；默认约每五条插入一个
   种子决定的探索位。探索仍受可见性、不感兴趣与多样性约束。
5. 优先排除本会话已曝光内容；候选池全看过则允许带疲劳的重复，诊断记 `repeat_fallback`。
   此标记不保证整个大世界都已看过。

关注流仅召回关注作者；搜索全文/话题作字面量匹配，再检查可见性，不受已看去重影响。
SQLite `lower` 主要支持 ASCII；没有中文分词、语义搜索或 Unicode casefold。

召回输出有上限，但热门/探索 SQL 仍可能扫描合格帖子。大世界需要索引/缓存。真实日期
需按世界导入约定转换为模拟 tick。

## 浏览与动作

`SocialSession.start(world, user_id)` 创建持久会话。卡片只有摘要和封面，`open_post`
才显示完整内容/图库/视频和评论。`scroll` 从当前固定列表取下一页，`refresh` 按当前
世界和反馈重排。每页默认六条，公开 `available_actions` 提供当前动作参数。

| 屏幕 | 动作 |
|---|---|
| 发现/关注/搜索 | 刷新、滚动、打开可见帖、不感兴趣、关注/取消关注可见作者 |
| 内容详情 | 返回、停留、赞/取消赞、收藏/取消收藏（平台允许）、评论、关注、不感兴趣 |
| 所有活动会话 | 搜索、发布文字、结束会话 |

模型不能猜未见的 ID 然后互动。预览不包含评论、隐藏分数、召回原因或主机路径；视觉
provider 只编码当前屏幕素材，base64 仅存在于模型请求。素材库、多媒体创作与全部
三平台原生 action 的会话覆盖属于下一阶段。

动作累加模拟使用时长 `elapsed_ms`。Runner 每轮按 seed/tick 打乱账号顺序，每账号至多
执行 `steps_per_tick` 次，一轮完成世界 tick 才加一。停留当前不独立推动世界钟。模型
通过 async `complete(messages)` 使用同一套工具，历史包含最近八步公开动作/结果。

失败留痕，并停止该账号本 tick 剩余动作，其他账号继续。轮数耗尽自动结束会话。当前
会话没有完整模型调用 provenance/费用报告或崩溃事务恢复；正式受控评测继续使用既有
Runner 的预算、checkpoint 和回滚机制。

## 曝光、存档与复现

`agora_request` 保存排序与卡片列表；`agora_exposure` **只保存实际显示页面**，同一
request/post 不重复计数，返回页面不再记曝光。打开和阅读分别记反馈，曝光不等于阅读。

`agora_session_event` 按步骤保存 action、result 和公开 observation。重开世界可恢复
会话查看或继续操作；原 SQLite snapshot/WorldArtifact 包含新增表。历史观察是当时快照，
不会随当前内容计数改写。每个会话和推荐请求都存配置。

同初始世界、seed、配置与规则策略可复现语义轨迹；模型回复/网络不是确定性因素。回放
读取历史记录，不重新调用模型。

## 控制台和 API

`agora serve <world_id>` 默认绑定 `127.0.0.1:8765`。可切换账号/会话、实时操作、逐步
回放、查看曝光话题与推荐分项。历史帧按钮禁用；“回到当前”才能继续活动会话。

| API | 用途 |
|---|---|
| GET `/api/world` | 世界、账号和会话列表 |
| GET `/api/session?id=1` | 公开观察、轨迹和单独的研究者推荐诊断 |
| POST `/api/session` | `{"user_id": 7}` |
| POST `/api/action` | `{"session_id": 1, "action_type": "refresh", "arguments": {}}` |
| GET `/media/<asset_id>` | 按数据库 ID 读取世界媒体 |

这是研究者拥有完整世界的本地控制台，包含隐藏诊断和所有世界媒体，不是待评模型的
HTTP 接口。模型使用 `SocialSession.observe/act`。单线程串行写 SQLite，多人服务和
鉴权需要另外实现。独立模拟进程与控制台应使用不同世界/Artifact 副本。
