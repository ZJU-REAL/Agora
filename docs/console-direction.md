# Developer / Viewer 方向约定

范围仍限于框架工作台；三种原生社媒页面保持独立。模式 Operate。

## Direction contract

THESIS：以实际账号画面为中心的社交模拟工作台。采用用户提供的产品重构建议，减少重复
导航和装饰容器，连接配置、启动、观察和复用配置的完整路径。模式 Operate。

OWN-WORLD：用户指定的 `agora_icon.png` 是正式图标和主视觉，保留原画。近白底、蓝紫色
标题与选中状态，少量桃粉、奶油金和薄荷色承接原图配色。文字标识保留在顶部，小幅
插画用于 Developer 标题区和 Viewer 空状态。白色内容区域、蓝紫选中状态和细线分组。

STORY：平台选择旁直接探索；区分受测与背景账号及模型；显示总动作预算并启动。进入
Viewer 后切换账号恢复各自位置，筛选操作并定位精确历史画面；可复用配置创建新实验。
统计、画面、理由和执行结果来自实际记录，不推断或生成缺失信息。

FIRST VIEWPORT：Developer 使用紧凑标题、平台选择与分组表单，右侧显示启动摘要。
Viewer 用紧凑实验标题和选择器，左侧窄账号列表、中间原生画面、右侧当前动作与记录。
桌面视口容纳画面及运行控制；窄屏账号列表横向排列，手机把详情放在平台画面下方。

FORM：seed: none (pinned)。用户要求“参考……前端整体优化与产品体验重构……不要机械的
一昧遵守……加入自己的思考”。保留指定插画品牌，采用文档的配置/观察分工与画面优先布局。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

命名交互：切换账号恢复独立回放位置；切换模式保留平台与实验。放大保持同一 iframe 和步骤。
色彩及按钮反馈仍为短过渡，无
持续飘动、粒子或动画循环；减少动态效果偏好下取消过渡。
