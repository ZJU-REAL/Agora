# Agora 0.4 当前能力与后续边界

## 本轮完成

- 三平台独立世界和面向 AI 的账号 API/客户端，平台 token 绑定用户与世界。
- 小红书图文/视频、图库位置、收藏专辑、评论/置顶、编辑删除和发现/关注/同城。
- X For You/Following、标准加权长度、原生回复、转发/引用、原帖互动与私有书签。
- Reddit 社区、内容类型、排序、互斥投票、独立 Crosspost 评论、社区可见性和版务权限。
- 对应三种页面布局、原生发布表单、素材上传和逐步操作回放。
- 统一决策事务、幂等回执、正确调用归因；观察进入记忆，账号动作按可用时间调度。
- 旧运行只读兼容，内部实验/受控评测保留，默认本地运行不依赖 Docker。
