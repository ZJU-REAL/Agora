# Agora 0.3 架构与下一阶段

2026-11-13。当前已连接产品、推荐和实验三条链，设计依据见 [相关工作](research.md)。

## 已实现

- 原生世界存储、增量 schema 迁移、模拟 tick、原生评论线程与复合动作事务。
- 内容寻址媒体、重复素材复用、账号素材库、图文草稿与发布过程。
- 个人主页、通知、连续浏览、公开理由/动作/结果/观察，以及有界账号记忆。
- 推荐 v2：六路召回、共同正反馈协同特征、反馈衰减、疲劳、多样性与探索。
- 页面创建独立实验、后台执行、进度、暂停/继续/停止、每账号观察、回放和完整导出。
- 原生模型/视觉适配、模型身份校验、已知 token/延迟/失败记录；默认安装不拉 CAMEL/Torch。
- 历史上游 runtime 已移至 `oasis/legacy/`，主世界不加载 Platform/Channel/Clock。
- 独立受控评测、Artifact、受众/Observer、预算和跨语境协议继续可用。

## 尚需完善

| 优先级 | 工作 | 验收 |
|---|---|---|
| P0 | 真实行为/推荐校准 | 匿名曝光、点击、停留、收藏与关注日志；独立用户/时间验证集；报告偏置、分布与误差 |
| P0 | 真实 LLM/VLM 实验 | 冻结 provider/模型/目标/预算，多 seed 配对；验证工具有效率、媒体理解、反馈适应和成本 |
| P1 | 更完整的社媒产品 | 视频过程、素材上传/生成、通知跳转、热评/分页、编辑/删除、三平台全部原生会话工具 |
| P1 | 更完整的社会行为 | 时间映射、在线/离线活动、动机/情绪/反思、关系状态接入自主策略；对照无记忆与无反馈 |
| P1 | 传播和干预分析 | 实际曝光分母、转发/回复传播树、跨社区扩散、延迟响应、置信区间与因果配对 |
| P2 | 大规模执行与恢复 | 批量特征缓存、ANN/全文索引、队列与分布式 actor、崩溃幂等恢复、共享控制台鉴权 |

开发策略包含人工编写的计划、文案与理由，用于检查基础设施；不能充当 LLM 能力、人类
行为一致性或真实平台推荐效果的实验结果。模型可以利用当前记忆接口，但完整反思系统
还未实现。主路径已脱离上游 runtime，不等于删除所有派生代码或完成全部研究假设。
