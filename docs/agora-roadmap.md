# Agora 架构审查与迭代路线

2026-11-13。项目目标扩展到可操作、可观察的 AI 社交沙盒。OASIS 是可逐步替换的
世界底座，Agora 自己拥有推荐、产品交互与研究协议。原有 Arena 仍用于控制变量。

## 审查结论

已有内容/媒体、评论树、关系状态、Artifact 隔离、模型 provider、预算与评估是有价值的
基础。主要不足是实际使用社媒的连续过程与传播机制缺失。

| 审查项 | 原来的实际行为 | 本轮改进 / 剩余边界 |
|---|---|---|
| 推荐 | 可见帖子按互动绝对量、兴趣、时效与关注相加 | 多路召回、反馈衰减、平滑质量、疲劳、多样性和探索；尚未训练/真实校准 |
| 刷新/浏览 | `observe` 直接给完整帖子和评论 | 卡片、详情、滚动、返回、停留；仅显示页面记曝光 |
| 搜索 | 只在 Feed 前 200 条中查找 | 全库匹配 ID，再作可见性过滤和排序，支持字面量通配符 |
| 曝光 | 受控观察先曝光大 Feed 再裁剪 | 只记请求集合，按实际观察顺序记名次 |
| NPC | tick 内主要围绕排名第一条自动互动 | 新 runner 支持多账号、位置偏置、连续工具动作和模型策略 |
| 视觉输入 | 评测层已有 VLM，沙盒缺少会话入口 | 模型会话只读取当前页面图片/视频帧；编码暂复用评测适配器 |
| 展示 | CLI 和离线分析脚本 | 浏览器操作、逐步观察回放、排序分项和话题分布 |
| 架构 | Agora API 与上游平台同处于 `oasis/` | 新服务在 `agora/`，有显式 backend；世界 CRUD 仍依赖 OASIS |

`agora-hybrid-v1` 是可解释、可复现的工程代理。它没有厂商参数、真实用户日志、训练样本
或 embedding 模型。规则受众也不代表人类。工程通过是开展校准实验的前提，不能替代
校准结果。

## 两种运行方式

- **沙盒 `agora simulate`**：反馈影响推荐，曝光内生变化，适合研究运营和传播。
- **Arena `agora-benchmark`**：控制内容池、曝光与预算，适合同条件比较 Candidate。

跨模式比较必须记录推荐配置与曝光条件。原 Arena 不会静默切换到自适应推荐；以后接入
时需单独协议版本、固定初始历史和多 seed 配对实验。

## 下一阶段与验收标准

### P0：独立世界内核

把 schema/migration、帖子/评论/关系/媒体 CRUD、模拟钟和事件序列迁到 `agora/world/`。
保留上游兼容 adapter，迁移带版本与校验，核心测试完全不导入 `oasis`。

验收：三平台测试在新内核与兼容 adapter 上通过；旧 Artifact 可迁移；同 seed 脚本语义
轨迹相同；推荐、前端与策略调度不用修改即可换世界后端。

### P0：真实行为与推荐校准

准备匿名曝光/点击/停留/收藏/关注日志，区分训练、校准和验证用户/时间窗口。先估计
位置偏置、时效、疲劳、冷启动和作者集中度，再引入可替换的 embedding 召回与点击/
停留预测。保留当前规则算法作为对照。

验收：在独立日志上报告排序质量、点击/停留分布、主题/作者覆盖与流量集中度，带样本量
和误差；模型/参数纳入 Artifact 指纹，不能只声称“更像真实”。

### P1：更完整的使用体验

新会话目前支持文字创作、卡片/详情/评论、搜索、收藏和关注。底座已有多图、视频、引用/
转发、楼中楼等，新会话与前端尚未覆盖全部动作。

继续做素材库和媒体创作、个人页、通知/回复收件箱、图集翻页、视频播放进度、评论分页/
热评及各平台原生工具，并明确阅读时长到模拟 tick 的映射。

验收：LLM/VLM 通过可见页面与素材白名单完成创作/回应/运营任务；无隐藏状态泄漏；
三平台有各自交互语义；无效/失败动作具备完整事务回滚与恢复协议。

### P1：长期社会行为与传播实验

已有受众关系记忆，需进一步接入会话策略的动机、情绪、活动时段与有界长期记忆。对
争议事件、重复转发、社区桥接和延迟响应给出明确机制，增加传播树、曝光链路、跨群体
扩散与配对干预统计。自主模型动作需完整记录模型身份、token、费用与失败。

验收：同预算多 seed，对照无记忆/无推荐反馈/不同参数；保存传播路径和实际曝光分母；
分别报告模型评估、规则推演与真人结果。

### P2：扩展与产品化

SQLite 单世界单写者适合小规模研究。后续需要批量特征缓存、候选索引、actor 调度、
任务队列、模型并发、动作幂等与恢复、大世界性能基准、共享控制台鉴权及实验比较面板。

在验证数据出来前，不宣称百万用户、真实社媒复现或正式情感对齐能力。
