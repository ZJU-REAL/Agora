# 三平台分发与社区行为 · Agora 0.8

新模拟默认 `agora-hybrid-v4`。三平台共享存储、可见性和曝光记录，分别处理召回来源、
反馈强度、质量目标与时间线规则。参数是可检查的模拟假设，尚未由真实用户日志拟合。

| 平台 | 召回与排序 | 平台行为 |
| --- | --- | --- |
| 小红书 | 兴趣、关注、收藏、实际阅读、新内容试探与重复疲劳；笔记时效衰减较慢 | 发现探索兴趣，关注按时间，同城结合地点与个性化；保留收藏专辑、图集顺序与生活经验 |
| X | 关注、二跳关系、关注者点赞、兴趣与协同召回；转发/回复、阅读与更快的时效衰减 | Following 按时间并过滤无关回复；转发继承主题，原帖/纯转发只占一个位置，引用独立 |
| Reddit | 订阅、学习的社区偏好、主题与新社区探索；净票、投票置信度与社区多样性 | Following 只含已加入社区，详情展示社区规则；Best 个性化，Hot 时间敏感，New 按时间，Top 按净票与时间窗 |

账号观察提供简短的平台使用语境，不强迫所有账号采用同一人设或语言，也不提供隐藏
分数。具体声音继续来自导入的 Persona 和实际社区规则。

## 反馈口径

- 小红书收藏强于点赞；X 私有书签弱于点赞，转发/回复有独立信号；Reddit 同时学习
  话题与社区，同一话题下的不同社区可以有不同偏好。
- 点赞/收藏/转发撤销写入相反反馈，重复提交不反复累积。加入收藏专辑只有新保存计
  反馈。Reddit 投票切换按实际前后状态差值计算。
- 同一展示请求反复打开只计一次。停留与实际视频播放共享 30 秒阅读预算；拖动
  进度条不算观看。图集只在看到新图片时计反馈，最多一份完整图集反馈。
- 打开率基于最近两个反馈半衰期内的真实展示，按用户+请求去重。打开必须匹配该
  展示请求，手动链接打开不能制造没有曝光分母的点击。
- 阅读证据是同一次展示里累计至少 15 秒的停留/播放，不代表语义理解或完播。
  排序使用平滑阅读比例，反复播放不算多个读者。
- X 纯转发使用原帖互动/阅读证据，反馈归到原帖。被拒绝或不可见的原帖不能通过
  纯转发重新分发；引用的内容保持独立。
- Reddit 大量评论不自动代表质量。多数反对票的争论不会仅靠回复量获得高质量
  加分；净票、Wilson 置信下界和有界评论量分别参与排序。

v4 新增配置 `graph_weight`、`community_weight`、`community_diversity_penalty`，见
`configs/environments/recommendation.hybrid.json`。平台默认值见 `agora/distribution.py`，
不是资料中确认的厂商常数。

## 原生榜单与资源

Reddit Hot/Top/New 在 SQL 中先过滤可见性、社区与虚拟时间，再排序、截取候选。
旧实现先取最近 500 条，可能漏掉旧热门帖或被不可见内容占满窗口。现在仍最多读取
500 个候选，最终 slate/页面继续限量。Best 各召回通道查询完整合格范围，不先把全库
载入 Python。时间窗口用实际 `tick_duration_ms` 换算。

没有增加运行时依赖、模型权重或种子数据。缓存、并发与内存限额保持原样；新增索引
支持关注边、社区候选与展示请求反馈匹配。历史回放仍读保存的快照，旧 v1/v2/v3 可选。

## 参考资料与边界

2026-11-23 实际读取：

- [X 当前公开 For You 实现](https://github.com/xai-org/x-algorithm)：网络内/外召回、
  多种行为预测、负反馈、多样性与过滤；2026-10 更新强调阅读完成与时间估计。
  它使用训练的检索/Transformer 模型，Agora 用关系与反馈近似机制，没有复现该模型。
- [X 历史算法](https://github.com/twitter/the-algorithm)：关系图与候选服务的历史参考。
- [Reddit 推荐说明](https://support.reddithelp.com/hc/en-us/articles/23511859482388-Reddit-s-Approach-to-Content-Recommendations)及
  [排序说明](https://support.reddithelp.com/hc/en-us/articles/19695706914196-What-filters-and-sorts-are-available)：
  本次通过官方 Help Center JSON API 读取正文；直接网页请求受阻。Hot/Wilson 仍参考
  公开历史形状，不代表当前 Reddit 生产模型。
- [小红书公开发现页](https://www.xiaohongshu.com/explore)：生活兴趣社区与个性化
  笔记语境；公开 HTML 不提供内部权重，未访问登录后的私人 Feed。

真实校准仍需匿名曝光日志、独立验证集和多 seed 对照。规则账号与测试夹具只能证明
机制可运行，不能证明模型能力或人群一致性。回归见 `tests/test_platform_distribution.py`，
完整验证见 [验证状态](validation.md)。
